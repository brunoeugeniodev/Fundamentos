# 02 - Vetores e estruturas

Nesta etapa comecei a juntar varios dados em uma mesma estrutura e a criar programas um pouco mais completos.

Os exercicios trabalham com vetores, `struct`, cadastros, datas, funcionarios, conjuntos e uma biblioteca simples.

Alguns arquivos usam C++ porque possuem metodos dentro de `struct` e outros recursos da linguagem.
