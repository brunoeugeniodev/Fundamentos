Esta pasta está reservada para a continuidade dos estudos de estruturas de dados. Atualmente contém apenas este README: não há implementação de árvore, programa executável ou resultado de testes nesta etapa.

## Objetivo proposto

Passar das estruturas lineares para uma organização hierárquica de nós. Os estudos anteriores de ponteiros, memória dinâmica e recursão fornecem a base para representar raiz, filhos e subárvores.

## Roteiro de desenvolvimento

Os itens abaixo são propostas, ainda não implementadas.

| Tema | Exercício proposto | O que observar |
| --- | --- | --- |
| Representação | Nó com valor e ponteiros para filhos | Raiz, folhas e árvore vazia |
| Árvore binária de busca | Inserção e busca segundo uma regra de ordenação | Relação entre altura e comparações |
| Percursos | Pré-ordem, em ordem e pós-ordem | Ordem de visita dos nós |
| Remoção | Nós sem filhos, com um filho e com dois filhos | Preservação da organização |
| Memória | Liberação de todos os nós | Percurso adequado para desalocação |

## Como documentar as futuras implementações

Cada exemplo poderá apresentar o problema, a representação, um comando de compilação e uma entrada com saída esperada. Casos de árvore vazia, valores repetidos e inserções ordenadas ajudarão a explicitar as decisões da implementação.

Enquanto esta etapa não recebe código, a [classificação de times](../08-projetos-e-exercicios/README.md) demonstra a integração dos conceitos já disponíveis.
