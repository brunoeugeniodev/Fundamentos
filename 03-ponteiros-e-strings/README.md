# 03 - Ponteiros e strings

Aqui comecei a trabalhar mais diretamente com memoria e textos.

Os exercicios usam ponteiros para strings, alocacao dinamica com `malloc` e liberacao de memoria com `free`. Tambem aparecem buscas e ordenacoes de nomes.

Esta foi uma etapa importante para entender que uma string em C e um conjunto de caracteres guardado na memoria.
